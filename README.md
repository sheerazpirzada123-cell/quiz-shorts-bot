# quiz-shorts-bot (ab: Explainer Shorts bot)

Har run par Gemini naya script likhta hai, Pollinations AI images banata hai, Kokoro male voice bolti hai,
captions + zoom/pan ke saath 1080x1920 Short banta hai aur YouTube par upload hota hai. Din mein 2 baar random time par.

Secrets: GEMINI_API_KEY, YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET, YOUTUBE_REFRESH_TOKEN
(optional: POLLINATIONS_API_KEY)

Tweak: voice `KOKORO_VOICE` (am_michael, am_fenrir, am_puck, am_adam), image style `IMAGE_STYLE`, random wait `MAX_DELAY_MIN` (workflow).
